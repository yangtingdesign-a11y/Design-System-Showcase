# Artisan UI Breadcrumb 面包屑样式规范

用于表达当前位置和页面层级，适合后台管理系统的详情页、配置页和多级业务页面。

## 视觉规则

默认样式：
- 上下内边距：10px
- 左侧内边距：0
- 右侧内边距：18px
- 底部分割线：`#CCCCCC`
- 字号：14px
- 链接悬浮色：主色 `#005CF1`

首页图标：
- 图标字号：14px
- 图标与文字间距：2px

## 设计建议

- 面包屑应放在页面内容顶部，靠近标题区域。
- 层级不宜过深，通常 2 到 4 级即可。
- 当前页只展示文本，不建议再做可点击链接。
- 如果页面已有强标题区，面包屑可以保持轻量，不要重复抢焦点。

## 走查清单

- 路径层级是否清晰。
- 当前页是否与可点击层级区分。
- 首页图标是否尺寸克制。
- 底部分割线是否不过重。
