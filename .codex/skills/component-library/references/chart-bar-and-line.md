# Artisan UI ChartBarAndLine 柱线组合图样式规范

用于在同一分类或时间轴上同时展示柱状指标和折线指标。

## 默认视觉

柱体：
- 渐变起色：`#579BFF`
- 渐变止色：`#D8E8FF`

折线：
- 默认颜色：`#E4558A`
- 面积辅助色：从 `#FF616150` 到 `#FF616120`

## 设计建议

- 柱状图通常表达数量、规模、次数。
- 折线通常表达比例、趋势、增长率。
- 两个指标单位不同，需要明确左右轴或单位说明。
- 不要把无关联的两个指标强行放在同一张图。

## 走查清单

- 柱和线是否分别有清晰含义。
- 两个单位是否标注清楚。
- 颜色是否一蓝一红，区分明显。
- 图例是否说明柱和线对应指标。
