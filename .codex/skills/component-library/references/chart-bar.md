# Artisan UI ChartBar 柱状图样式规范

用于展示单系列分类数据对比，适合数量、次数、规模、排名等场景。

## 默认视觉

柱体颜色：
- 默认渐变起色：`#579BFF`
- 默认渐变止色：`#D8E8FF`

图表区域：
- 放在 ChartBox 容器中
- 宽高跟随外层容器
- 坐标轴和标签保持克制

## 设计建议

- 分类数量不宜过多，过多时改用横向条形或分页。
- 柱体颜色用于强调数据系列，不要每根柱子随意换色。
- 数值差距过大时注意坐标轴起点和单位说明。
- 排名类图表建议按数值排序。

## 走查清单

- 是否使用蓝色渐变作为默认柱体。
- 分类标签是否可读。
- 单位是否明确。
- 柱体数量是否没有拥挤。
