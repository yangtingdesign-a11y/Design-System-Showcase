# Artisan UI ChartBox 图表容器样式规范

ChartBox 是图表的基础承载容器，用于让 ECharts 图表填满指定区域。

## 视觉规则

容器：
- 宽度：100%
- 高度：100%
- 图表画布填满容器

加载态：
- 加载区域宽高：100%
- 背景透明
- 不额外增加装饰背景

## 设计建议

- 图表外层尺寸必须明确，避免实现时高度塌陷。
- 图表区域不需要额外卡片化，是否卡片由页面布局决定。
- 加载态不要遮挡图表标题和关键操作，通常只覆盖图表内容区。
- 多图表并列时，容器高度要统一。

## 走查清单

- 图表容器是否有明确宽高。
- 加载态是否轻量透明。
- 图表是否填满容器而不溢出。
- 多个图表区域是否高度一致。
