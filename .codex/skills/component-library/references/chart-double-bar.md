# Artisan UI ChartDoubleBar 双柱图样式规范

用于同一分类下两组指标的并列对比，例如本期/同期、计划/实际、男/女等。

## 默认视觉

第一组柱体：
- 渐变起色：`rgb(96,137,247)`
- 渐变止色：白色

第二组柱体：
- 渐变起色：`rgb(242,163,102)`
- 渐变止色：白色

## 设计建议

- 两组指标必须有清晰图例。
- 不建议扩展到三组以上，超过两组优先使用多柱图。
- 两组颜色要有足够区分度，但不应过度饱和。
- 分类数量较多时注意横轴标签拥挤。

## 走查清单

- 两组柱体颜色是否区分明确。
- 图例是否说明两组含义。
- 同一分类下两根柱是否视觉成组。
- 是否避免把双柱图用于无关指标对比。
