# Artisan UI ChartLegend 图例样式规范

用于图表旁边或下方的自定义图例，支持横向和纵向布局。

## 视觉规则

图例容器：
- 背景：白色
- 圆角：6px
- 内边距：15px 20px 0
- 阴影：`0 2px 6px 0 #EDEDED`

标题：
- 字号：14px
- 颜色：`#333333`
- 行高：15px

图例项：
- 字号：14px
- 颜色：`#333333`
- 行高：15px
- 项目底部间距：20px
- 色块尺寸：10px × 10px
- 色块圆角：3px
- 色块右间距：8px

横向图例：
- 内容顶部间距：10px
- 项目右间距：10px
- 双列横向布局单项宽度约 280px

## 设计建议

- 图例颜色必须与图表数据系列一一对应。
- 数值和占比可以放在图例后方，但不要造成拥挤。
- 图例过多时优先换行或分组，不要压缩到难以阅读。
- 图例本身不应比图表更抢眼。

## 走查清单

- 色块是否为 10px 且圆角 3px。
- 图例文字是否为 14px。
- 图例顺序是否与图表视觉顺序一致。
- 横向/纵向布局是否符合空间关系。
