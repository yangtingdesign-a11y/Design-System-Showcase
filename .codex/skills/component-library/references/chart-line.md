# Artisan UI ChartLine 折线图样式规范

用于展示单个指标随时间或顺序变化的趋势。

## 默认视觉

折线颜色：
- 默认色：`#579BFF`

图表区域：
- 坐标轴保持轻量
- 重点表达趋势，而不是装饰曲线

## 设计建议

- 横轴优先使用时间、阶段或有序类别。
- 单折线适合突出一个核心指标。
- 如果有多个指标，使用多折线图。
- 异常点可以在产品说明中标注，不要随意加重整条线。

## 走查清单

- 折线是否使用默认蓝色。
- 横轴是否有明确顺序。
- 单位是否标注清楚。
- 是否避免用折线图展示无序分类。
