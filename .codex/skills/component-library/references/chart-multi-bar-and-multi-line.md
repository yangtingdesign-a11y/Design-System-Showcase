# Artisan UI 多柱多折线组合图样式规范

用于多个柱状系列和多个折线系列共用同一分类或时间轴的复杂分析场景。

## 默认视觉

柱状系列：
- 默认蓝色渐变体系
- 渐变起色：`#579BFF`
- 渐变止色：`#D8E8FF`

折线系列：
- 默认线色包含 `#73A0FA`
- 多条折线需要通过图例区分

## 设计建议

- 仅在业务确实需要同时比较多个数量和多个趋势时使用。
- 指标过多会显著增加认知负担，优先考虑拆成多张图。
- 必须明确每个系列的单位、图例和轴含义。
- 不建议在小卡片中使用该复杂图表。

## 走查清单

- 是否确实需要多柱加多线。
- 图例是否能完整解释系列。
- 左右轴和单位是否清楚。
- 图表空间是否足够承载复杂信息。
