# Artisan UI ChartMultiBar 多柱图样式规范

用于同一分类下多个系列的并列对比。

## 默认视觉

默认柱体系列使用蓝色渐变体系：
- 渐变起色：`#579BFF`
- 渐变止色：`#D8E8FF`

图表提示和图例应能区分每个系列。单位可在图表区域中显示为“单位：xxx”。

## 设计建议

- 适合 2 到 4 个系列并列比较。
- 系列过多会造成柱体过细，应改用分组、筛选或表格。
- 分类数量较多时要注意横轴拥挤。
- 同一系列颜色在不同页面应保持稳定。

## 走查清单

- 系列数量是否适合多柱图。
- 图例是否完整说明每个系列。
- 单位是否明确。
- 柱体是否没有过细或拥挤。
