# Artisan UI ChartPie 饼图样式规范

用于展示整体构成和占比关系，支持饼图和环形图。

## 默认颜色

默认色板：
- `#3B82F6`
- `#818CF9`
- `#C084FC`
- `#22C55E`
- `#F97316`
- `#EF4444`
- `#0FC1A6`
- `#F8A419`
- `#4153F8`
- `#F84FB0`
- `#7941DB`
- `#0FC6F1`
- `#F84A60`
- `#36CFC9`
- `#72D43A`
- `#6C7380`

环形图中心：
- 总数数字字号：32px
- 总数说明字号：23px
- 中心区域可点击时需要有明确交互说明

标签：
- 标签可使用圆角 8px
- 标签内边距较克制
- 辅助文字可使用 `#999999`

## 设计建议

- 分类数量过多时不要使用饼图，优先用条形图或列表。
- 饼图适合看构成，不适合精确比较相近数值。
- 环形图中心只放一个核心总数或名称。
- 小占比过多时应合并为“其他”。

## 走查清单

- 色板是否与图例一致。
- 中心总数是否清晰。
- 分类数量是否适合饼图。
- 标签是否没有互相遮挡。
