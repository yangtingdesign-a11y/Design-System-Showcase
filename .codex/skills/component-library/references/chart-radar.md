# Artisan UI ChartRadar 雷达图样式规范

用于展示多个维度上的综合表现，适合能力评价、画像分析、维度评分。

## 默认颜色

系列色：
- `#73A0FA`
- `#73DEB3`
- `#F7C739`
- `#EB7E65`
- `#A285D2`
- `#FFAB67`
- `#FFABCC`
- `#7585A2`
- `#3B70DB`
- `#CD8050`

辅助色：
- 维度文字：`#999999`
- 分割线：`#BFBFBF` / `#E9E9E9`
- 内容文字：`#666666`
- 高亮文字可用白色

## 设计建议

- 维度数量建议 4 到 8 个。
- 每个维度应是同一量纲或可归一化评分。
- 不适合展示绝对值差异很大的指标。
- 多对象对比不宜超过 3 到 4 个。

## 走查清单

- 维度是否表达清楚。
- 颜色是否能区分不同对象。
- 指标口径是否可比较。
- 维度数量是否没有过多导致拥挤。
