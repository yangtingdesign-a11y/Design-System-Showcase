# Artisan UI CheckboxTree 树状选择器样式规范

用于有父子层级的勾选场景，适合权限配置、分类选择、资源范围选择。

## 视觉规则

容器：
- 边框：`#E5E7EB`
- 圆角：4px
- 上下外边距：4px

分组标题：
- 内边距：12px
- 主标题字号：16px
- 主标题字重：500
- 主标题颜色：`#333333`
- 副标题字号：14px
- 副标题颜色：`#888888`

子选项：
- 每项内边距：12px
- 文字颜色：`#333333`
- 字重：500
- 底部分割线：`#E5E7EB`
- 复选框左缩进：32px
- 最后一项不显示分割线

## 设计建议

- 父级标题应概括子选项含义。
- 副标题用于补充说明，不要承载关键信息。
- 层级不宜过深，复杂权限建议拆成多个分组。

## 走查清单

- 容器是否有 4px 圆角和浅灰边框。
- 父标题与子选项是否层级清楚。
- 子选项分割线是否克制。
- 勾选态是否与主色体系一致。
