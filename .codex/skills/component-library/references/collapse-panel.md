# Artisan UI CollapsePanel 折叠面板样式规范

用于可展开/收起的内容分组，适合复杂配置、表单分段、长页面内容组织。

## 视觉规则

面板内容：
- 背景：白色
- 内容内边距：0 20px 20px 20px

面板头部：
- 高度：约 50px
- 背景：从 `#F7F9FE` 到 `#FFFFFF` 的轻渐变
- 左侧标题标识：4px × 16px
- 标识颜色：`#4491FA`
- 标识与标题间距：8px
- 标题字号：14px
- 标题颜色：`#333333`

展开/收起图标：
- 图标尺寸：11px × 11px
- 位置靠近标题区域

错误提示：
- 错误文字颜色：红色
- 与标题间距：4px

## 设计建议

- 适合承载较长内容，不适合只包一两行简单信息。
- 面板标题要说明内容类型，不要使用“更多信息”这类笼统文案。
- 右侧可放少量操作或状态，不要放复杂工具栏。

## 走查清单

- 面板头部是否有浅色背景和左侧标识。
- 标题是否 14px 且表达清楚。
- 收起/展开状态是否容易识别。
- 内容区内边距是否保持 20px 节奏。
