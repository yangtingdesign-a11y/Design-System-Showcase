# Artisan UI DatePickerGroup 日期选择器组样式规范

用于开始日期和结束日期并列输入，适合查询筛选、有效期设置、时间范围录入。

## 视觉规则

日期组：
- 横向排列
- 中间连接符使用短横线
- 连接符左右间距：5px
- 输入框样式跟随所在表单场景

在查询表单中：
- 输入框高度：36px
- 左右内边距：8px
- 日期前缀图标可弱化或隐藏

## 设计建议

- 开始与结束字段应保持同宽。
- 连接符只做分隔，不要设计成按钮。
- 如果需要精确到时分秒，提前在原型中标注格式。
- 对于常用范围，可配合快捷选项。

## 走查清单

- 两个日期输入是否对齐。
- 中间连接符是否有 5px 左右间距。
- 日期格式是否在设计或说明中明确。
- 是否处理开始晚于结束的错误场景。
