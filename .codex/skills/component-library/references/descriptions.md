# Artisan UI Descriptions 描述列表样式规范

用于展示只读详情信息，适合详情页、审批信息、基础资料、摘要字段。

## 视觉规则

容器：
- 内边距：20px
- 背景：白色

分组内容：
- 背景：`#F5FAFF`
- 圆角：6px
- 内边距：12px 20px
- 宽度：父容器减 40px

字段标签：
- 颜色：`#666666`
- 字号：14px
- 文本右对齐
- 垂直居中

字段内容：
- 颜色：`#333333`
- 字号：14px

## 设计建议

- 用于只读信息，不适合编辑录入。
- 同一组字段的标签宽度应保持一致。
- 内容为空时要有统一占位，如 `--`。
- 长内容需要省略、换行或详情展开策略。

## 走查清单

- 容器是否有 20px 内边距。
- 标签与内容是否颜色区分。
- 分组块是否使用浅蓝背景和 6px 圆角。
- 空值展示是否统一。
