# Artisan UI DynamicForm 动态表单样式规范

用于配置项、详情编辑、弹窗表单、抽屉表单和表格内编辑表单。

## 表单项规则

默认表单项：
- 左右外边距：10px
- 底部间距：18px
- 标签颜色：`#000000`
- 内容文字：`#333333`
- 输入文字：`#555555`
- 禁用文字：`#999994`
- 输入框高度：32px
- 单选项行高：32px

表单内容区：
- 表单宽度：100%
- 内容区域自适应填满
- Select 和日期选择器默认占满内容宽度

## 分组和提示

分组内容块：
- 背景：`#F5FAFF`
- 圆角：6px
- 内边距：12px 20px

必填标记：
- 使用红色星号
- 颜色：`#F56C6C`
- 与标签间距：4px

帮助提示：
- 图标颜色：`#E58907`
- 鼠标悬浮可点击

省略提示浮层：
- 宽度：600px
- 默认支持 2 行省略

## 设计建议

- 表单项应按业务逻辑分组，不要只按控件类型堆叠。
- 必填项标记必须清晰，避免只在校验后提示。
- 复杂说明使用帮助图标或分组说明，不要塞进标签。
- 只读表单也要保持表单节奏，不要随意改成普通文本列表。

## 走查清单

- 输入框是否为 32px 高。
- 表单项底部间距是否为 18px。
- 必填星号是否清晰。
- 分组块是否使用浅蓝背景和 6px 圆角。
