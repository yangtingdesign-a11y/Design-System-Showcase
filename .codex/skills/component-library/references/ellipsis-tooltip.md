# Artisan UI EllipsisTooltip 文本省略提示样式规范

用于长文本在有限空间中的展示和完整内容查看。

## 视觉规则

默认表现：
- 文本按指定行数截断
- 超出时显示省略
- 悬浮后展示完整内容
- 默认提示容器最大宽度：300px

常见行数：
- 表格中通常使用 1 行省略
- 表单或详情中可使用 2 行省略

## 设计建议

- 用于辅助阅读，不要把关键判断信息完全藏进 tooltip。
- 如果用户需要对比完整内容，应该加宽列或提供详情。
- 长编号、长名称、长路径适合使用该组件。
- 短文本不需要强行加提示。

## 走查清单

- 省略行数是否符合场景。
- 悬浮提示宽度是否足够阅读。
- 关键内容是否有更稳定的查看方式。
- 多个 tooltip 是否不会互相遮挡。
