# Artisan UI HeaderAgile 轻量页头样式规范

用于更轻量的页面标题栏，适合详情页、抽屉式内容页、嵌入式管理页。

## 视觉规则

容器：
- 高度：48px
- 宽度：全宽减 24px
- 左右内边距：12px
- 背景：白色
- 底部分割线：`rgba(232, 234, 236, 1)`

标题：
- 字号：16px
- 颜色：`#333333`
- 行高：48px
- 与相邻元素间距：12px

返回区：
- 高度：48px
- 返回图标字号：24px
- 图标右间距：12px

分隔线：
- 高度：24px
- 上下外边距：12px
- 颜色：`#E8EAEC`
- 宽度：2px

## 二级标题项

- 行高：47px
- 项间距：12px
- 悬浮/选中文字：主色 `#005CF1`
- 选中底线：3px 主色
- 禁用文字：`#C0C4CC`

## 设计建议

- 适合轻量页面，不适合复杂多层导航。
- 标题应简短明确，右侧插槽可放少量操作。
- 二级标题项不宜过多，避免挤满 48px 顶栏。

## 走查清单

- 顶栏是否保持 48px 高度。
- 标题、返回、分割线是否垂直居中。
- 选中态是否使用主色底线。
- 禁用态是否弱化明显。
