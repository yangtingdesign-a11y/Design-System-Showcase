# Artisan UI Header 页头样式规范

用于页面顶部的标题区和多级业务切换区，常见于详情页、统计页、业务模块页。

## 一级页头

默认样式：
- 容器背景：白色
- 内边距：10px 16px
- 一级标题/标签字号：18px
- 一级区域高度：36px
- 主分割线：3px，颜色 `#4E87ED`
- 一级选中强调色：`#FE8C00`

无二级导航时：
- 底部分割线：`#EDEEF2`
- 文字颜色：`#333333`
- 激活文字：`#000000`

## 二级和三级切换

二级区域：
- 字号：14px
- 背景：`#F7F9FE`
- 内边距：8px 0 7px 20px
- 选中背景：`#EDF2FF`
- 选中文字：`#4E87ED`
- 圆角：6px

三级区域：
- 背景：`#EDF2FF`
- 行高：40px
- 字号：14px
- 选中文字：`#4E87ED`

## 返回入口

返回入口位于右侧：
- 字号：14px
- 颜色：主色 `#005CF1`
- 图标与文字间距：4px

## 设计建议

- Header 适合承载页面级标题和业务分组，不要塞入大量筛选控件。
- 多级切换要有明显层级，一级、二级、三级不要使用完全相同样式。
- 返回入口只在有明确上一级页面时使用。

## 走查清单

- 标题层级是否清楚。
- 当前选中项是否有明确视觉反馈。
- 二级/三级切换是否没有拥挤换行。
- 返回入口是否出现在合适位置。
