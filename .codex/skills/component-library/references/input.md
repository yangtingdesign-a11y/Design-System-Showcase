# Artisan UI Input 输入框样式规范

Input 组件整体继承 Element UI 输入框风格，并受 Artisan 全局主题色控制。

## 视觉规则

常规输入框：
- 表单内常用高度：32px 或 36px，跟随所在组件
- 文字颜色：`#555555`
- 聚焦边框：主色 `#005CF1`
- 禁用文字：弱化灰色

在查询表单中：
- 高度：36px
- 圆角：8px
- 左右内边距：8px

在动态表单中：
- 高度：32px
- 行高：32px

## 设计建议

- 输入框宽度应跟随表单栅格，不要孤立设置奇怪宽度。
- 占位文案应说明输入内容，如“请输入名称”。
- 禁用态用于不可编辑，不应用来表达未选中。
- 有单位的输入项使用后缀说明，避免把单位写进占位符。

## 走查清单

- 输入框高度是否与所在场景一致。
- 聚焦态是否使用主色。
- 禁用态是否明显弱化。
- 占位文案是否具体。
