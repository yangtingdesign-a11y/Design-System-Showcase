# Artisan UI NavAnchor 旧版锚点导航样式规范

这是旧版页内锚点样式，主要用于存量页面保持一致。新页面优先使用新版 `NavAnchor` 规范。

## 视觉结构

旧版结构通常包含：
- 顶部导航容器
- 横向锚点列表
- 激活项
- 激活下划线
- 内容滚动区域

默认内容区域会为顶部导航预留约 52px 的上方距离。

## 设计建议

- 存量页面只做必要对齐，不建议引入新的视觉变化。
- 新页面不要混用新版和旧版锚点样式。
- 如果需要重构，优先迁移到新版锚点规范。

## 走查清单

- 当前页面是否确实为旧版锚点。
- 激活状态和滚动定位是否仍可用。
- 与新版锚点是否没有在同一页面混用。
