# Artisan UI NavAnchor 锚点导航样式规范

用于长页面内部的分段定位，适合复杂详情页、长表单、配置页面和说明页面。

## 视觉定位

锚点导航用于“当前页内定位”，不是跨页面导航。它应帮助用户快速跳到某一段内容，并反馈当前所在段落。

## 设计规则

- 顶部锚点栏建议固定在内容区域上方。
- 锚点项文案应对应页面中的分组标题。
- 当前锚点需要有明显激活态。
- 内容滚动时锚点状态应同步变化。
- 锚点区域与正文之间需要保留清晰间距。

## 设计建议

- 锚点数量建议 3 到 8 个。
- 锚点文案使用名词短语，如“基础信息”“审批记录”“附件信息”。
- 不建议把操作按钮放进锚点栏。
- 如果页面内容很短，不需要使用锚点。

## 走查清单

- 锚点项是否与正文分组一一对应。
- 当前锚点是否容易识别。
- 点击锚点后页面定位是否符合预期。
- 锚点栏是否没有遮挡正文内容。
