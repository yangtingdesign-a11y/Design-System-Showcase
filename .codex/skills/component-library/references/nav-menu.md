# Artisan UI NavMenu 侧边导航样式规范

用于后台系统左侧导航，支持展开、折叠、多级菜单和图标菜单。

## 视觉规则

容器：
- 展开宽度由产品布局决定
- 折叠宽度：64px
- 高度：100%
- 滚动条宽度：4px
- 滚动条颜色：`#D9D9D9`

菜单项：
- 高度：48px
- 字号：14px
- 默认文字：`#333333` 或 `#666666`
- 图标尺寸：16px
- 图标与文字间距：12px
- 激活文字：主色 `#005CF1`
- 悬浮/激活背景：`#ECF2FD` 或 `#ECF5FF`

折叠控制：
- 控制按钮尺寸：22px × 30px
- 背景：白色
- 边框：`#E8EAEC`
- 圆角：4px

## 设计建议

- 一级菜单文案保持短，避免折叠后依赖长 tooltip。
- 菜单图标应风格统一，线性/面性不要混用。
- 当前页面所在菜单必须有明显激活态。
- 多级菜单层级不宜过深，通常不超过三级。

## 走查清单

- 菜单项是否保持 48px 高度。
- 图标与文字间距是否为 12px。
- 激活态是否使用主色和浅蓝背景。
- 折叠状态是否仍能通过图标和提示识别。
