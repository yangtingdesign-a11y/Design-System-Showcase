# Artisan UI SearchFormLive 即时筛选表单样式规范

用于无需点击查询按钮即可切换条件的筛选区，适合数据看板、分类列表、快捷过滤。

## 筛选行规则

每行筛选：
- 高度：46px
- 字号：14px
- 文字颜色：`#333333`
- 左右内边距：20px
- 标签颜色：`#666666`
- 标签与选项间距：10px

响应式标签宽度：
- 小于 1560px：标签 110px
- 1560px 到 1919px：标签约 8%
- 1920px 及以上：标签约 7%

## 选项样式

普通选项：
- 高度：30px
- 左右内边距：10px
- 默认透明边框
- 选项间距：6px

选中态：
- 边框：主色 `#005CF1`
- 选中图标：14px × 14px
- 图标背景：主色
- 图标颜色：白色

全部按钮：
- 圆角：15px
- 内边距：5px 15px
- 选中/悬浮背景：主色
- 选中/悬浮文字：白色

## 操作按钮

展开/收起按钮：
- 高度：20px
- 宽度：70px
- 字号：12px
- 文字颜色：`#666666`
- 边框：`#EBEBEB`
- 图标颜色：`#999999`

## 设计建议

- 适合条件切换频繁的场景，不适合复杂精确查询。
- 每行选项不要过多，超出时使用“更多”弹层。
- 选中态需要同时依靠边框和图标，不只靠颜色。

## 走查清单

- 筛选行是否保持 46px 高度。
- “全部”和具体选项是否区分清楚。
- 选中态是否有主色边框和勾选图标。
- 更多弹层是否用于超长选项。
