# Artisan UI SearchForm 查询表单样式规范

用于列表页、报表页、台账页中的查询条件区域。

## 布局规则

表单区域：
- 使用横向换行布局
- 字段行高：46px
- 字段左右内边距：10px
- 支持 2、3、4、5 列布局
- 2 列：每项 50%
- 3 列：每项 33%
- 4 列：每项 25%
- 5 列：每项 20%

标签与输入区：
- 标签宽度：25%
- 输入区宽度：75%
- 标签右内边距：6px
- 标签字号：14px
- 标签颜色：`#374151`
- 输入框高度：36px
- 输入框圆角：8px

## 按钮区

按钮默认：
- 宽度：80px
- 高度：36px
- 圆角：8px
- 字号：14px
- 查询按钮使用主色 `#005CF1`
- 按钮组顶部间距：10px

展开/收起：
- 使用文字加图标
- 图标跟随主色悬浮态
- 用于筛选项较多时控制高度

## 设计建议

- 常用筛选项放在第一行。
- 不常用筛选项放到展开区域。
- 查询和重置按钮保持稳定位置。
- 单行表单可使用独占布局，输入区宽度约 65%。

## 走查清单

- 字段高度是否为 46px。
- 输入框是否为 36px 高和 8px 圆角。
- 标签和输入框比例是否清晰。
- 展开/收起是否只在筛选项较多时出现。
