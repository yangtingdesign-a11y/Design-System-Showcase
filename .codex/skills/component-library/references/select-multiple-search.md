# Artisan UI SelectMultipleSearch 多选搜索样式规范

用于从大量选项中多选对象，并在页面中展示已选结果。

## 已选项样式

已选项容器：
- 背景：`#F5F6F8`
- 内边距：4px 6px
- 字号：14px
- 上下间距：3px

已选文本：
- 文字颜色：`#333333`
- 左右内边距：4px
- 最大宽度：120px
- 超长使用省略

删除图标：
- 尺寸：16px × 16px
- 圆角：8px
- 背景：`#EBFBFA`
- 颜色：`#2CC29E`
- 字号：12px
- 与文本间距：6px

添加入口：
- 图标颜色：主色 `#005CF1`
- 图标字号：26px
- 左间距：6px
- 禁用态：`#C0C4CC`

## 弹层规则

- 弹层宽度：约页面宽度的 25%
- 内容内边距：15px

## 设计建议

- 适合已选项需要持续可见的场景。
- 已选项过多时要考虑折叠、换行或详情查看。
- 删除入口要明显，但不要比内容本身更抢眼。

## 走查清单

- 已选项是否有浅灰背景。
- 删除图标是否为 16px 圆形。
- 添加图标是否使用主色。
- 长文本是否有省略方案。
