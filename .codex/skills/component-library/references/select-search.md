# Artisan UI SelectSearch 搜索选择样式规范

用于选项较多、需要搜索或远程加载的下拉选择。

## 视觉规则

下拉区域：
- 弹层宽度：约页面宽度的 25%
- 更多/空状态区域内边距：15px
- 加载/空状态区域高度：200px
- 宽度：100%

输入区域：
- 继承 Element UI Select
- 选中态、聚焦态使用主色 `#005CF1`

## 设计建议

- 适合组织、人员、业务对象等大量选项。
- 搜索结果为空时要显示清楚的空状态。
- 远程加载时避免弹层高度跳动。
- 不建议用于只有 3 到 5 个固定选项的小选择。

## 走查清单

- 弹层是否有足够宽度显示长选项。
- 空状态/加载状态是否明确。
- 搜索输入和结果区域是否对齐。
- 是否避免把简单选择复杂化。
