# Artisan UI Select 选择器样式规范

用于单选、多选、带图标选项和表单中的下拉选择。

## 视觉规则

基础选择器继承 Element UI，并使用 Artisan 主色：
- 聚焦边框：主色 `#005CF1`
- 选中项文字：主色
- 多选选中项文字：主色，字重 400
- 表单内宽度：通常 100%

图标选项：
- 前缀图标尺寸：16px × 16px
- 前缀图标左间距：8px
- 选项图标右间距：6px
- 图标颜色：`#606266`

## 设计建议

- 选项数量较少且固定时使用 Select。
- 选项过多需要搜索时，优先使用带搜索能力的选择器。
- 选项文案要可区分，避免多个近似名称。
- 脱敏选择场景要确保展示值与真实值的关系清晰。

## 走查清单

- 选择器宽度是否跟随表单列宽。
- 选中态是否使用主色。
- 图标尺寸是否统一为 16px。
- 长选项是否有截断或提示方案。
