# Artisan UI SubHeader 副标题样式规范

用于页面内分组标题，适合表单分段、详情信息块、表格上方小标题。

## 视觉规则

默认样式：
- 高度：50px
- 标题字号：16px
- 文字颜色：`#333333`
- 文字行高：24px
- 左侧强调线：4px，颜色为主色 `#005CF1`
- 强调线高度：20px
- 强调线圆角：2px
- 强调线右侧间距：10px

图标模式：
- 图标字号建议：25px
- 图标与文字保持紧凑，不要形成大标题样式

## 设计建议

- 用于区块标题，不要替代页面主标题。
- 一个页面可以出现多个副标题，但间距和层级要一致。
- 当区块内容较少时，可以省略副标题，避免页面过碎。

## 走查清单

- 副标题是否为 16px。
- 左侧主色强调线是否清楚但不过重。
- 标题与正文内容是否有合理分组关系。
- 同页多个副标题是否样式一致。
