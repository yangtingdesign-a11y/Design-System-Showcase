# Artisan UI SvgIcon 图标样式规范

用于加载 SVG 图标，常见于导航、按钮、状态提示和辅助说明。

## 视觉规则

默认图标：
- 宽度：1em
- 高度：1em
- 颜色继承当前文字色
- 与文字搭配时按当前字号缩放

## 设计建议

- 图标应服务于识别，不要只做装饰。
- 同一页面图标风格要统一。
- 与文字搭配时，图标大小跟随文字字号。
- 可点击图标需要有悬浮态或明确点击区域。

## 走查清单

- 图标是否与文字基线对齐。
- 图标颜色是否遵循当前语义。
- 同类图标尺寸是否一致。
- 点击图标是否有足够热区。
