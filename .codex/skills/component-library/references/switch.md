# Artisan UI Switch 开关样式规范

Switch 组件继承 Element UI 开关样式，并使用 Artisan 全局主色表达开启状态。

## 使用场景

适合：
- 启用/停用
- 开启/关闭
- 是否允许
- 简单二元设置

不适合：
- 多选项切换
- 需要立即确认风险的破坏性操作
- 文案复杂的配置项

## 视觉规则

- 开启态使用主色 `#005CF1`
- 关闭态使用默认灰色
- 禁用态整体弱化
- 开关旁边应有清晰标签说明状态含义

## 设计建议

- 开关改变后如果立即生效，需要在文案或交互中明确。
- 高风险状态切换建议增加二次确认。
- 不要只用颜色解释开关含义，最好配合标签。

## 走查清单

- 开启态是否使用主色。
- 标签是否说明“开”代表什么。
- 禁用态是否不可误触。
- 高风险开关是否有确认机制。
