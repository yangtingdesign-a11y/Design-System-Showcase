# Artisan UI 表格组件样式规范

在设计 Artisan 体系下的后台管理系统、数据看板、查询列表页、配置维护页、审批列表、操作记录页时，使用这份规范来约束表格样式。

目标是让产品原型和设计稿尽量贴近已实现的 `ArTable` 组件，减少从设计到开发落地时的视觉偏差。

## 设计定位

Artisan 表格是一个偏工作台、偏管理后台的数据展示区域。它应该看起来稳定、克制、信息密度适中，方便用户快速扫描、比较和操作。

适合用于：
- 查询结果列表
- 业务记录列表
- 配置项维护表格
- 审批、流转、操作历史
- 可编辑的表格录入
- 带有编辑、删除、上移、下移、查看等操作的列表

不建议把它设计成营销卡片、装饰性看板模块或大面积展示区。表格的核心价值是承载数据、支持筛选、比较和重复操作。

## 结构组成

一个标准表格区域通常包含：
- 表格容器
- 表头
- 表格行
- 可选的固定列
- 可选的操作列
- 可选的分页区域
- 空数据状态
- 异常状态

当前组件实现中对应的主要结构标识包括：
- `.data-table-container`
- `.data-table`
- `.data-table-pagination`
- `.table-action-btn-group`
- `.table-edit-input`
- `.data-table-empty`

产品和设计稿中不需要直接标注这些类名，但在设计说明或交付给开发时，可以用它们作为实现溯源。

## 核心尺寸

默认表格尺寸建议如下：

| 项目 | 规格 |
| --- | --- |
| 表格文字字号 | 14px |
| 表头高度 | 44px |
| 普通行高度 | 44px |
| 可编辑行高度 | 48px |
| 行内编辑输入框高度 | 30px |
| 分页与表格间距 | 15px |
| 分页底部间距 | 5px |
| 滚动条宽度 | 6px |
| 操作按钮文字间距 | 12px |
| 帮助图标尺寸 | 17px |
| 筛选图标尺寸 | 14px |
| 文本提示浮层宽度 | 300px |

设计时要尽量保持行高稳定。不要因为图标、标签、按钮或换行文本导致行高忽高忽低，除非业务明确需要多行展示。

## 色彩规范

表格使用 Artisan 的主色作为操作和选中状态的强调色。

| 色彩角色 | 色值 | 使用场景 |
| --- | --- | --- |
| 主色 | `#005CF1` | 行操作、当前分页、选中态控件 |
| 表头背景 | `#F1F6FE` | 表头单元格 |
| 正文文字 | `#333333` | 表格主要内容 |
| 次要文字 | `#888888` / `#999999` | 分页数字、禁用状态 |
| 边框线 | `rgba(230, 234, 238, 1)` | 表格外框、单元格分割线 |
| 斑马纹行 | `#F9FAFD` | 偶数/间隔行背景 |
| 错误标记 | `#B94A48` | 单元格错误角标 |

主色在工程中通过 `--color-primary` 控制。设计主题切换时，应优先调整主题色变量，而不是逐个改表格里的按钮、分页和选中状态。

## 表头样式

表头需要比正文更明确，但不应过重。

表头默认样式：
- 背景色：`#F1F6FE`
- 文字色：`#333333`
- 字重：600 / Semibold
- 字号：14px
- 行高：22px
- 文本默认单行展示

如果字段名称很长，优先考虑精简命名，再配合帮助图标或提示说明。密集型后台表格中不建议大量使用双行表头。

## 表格行样式

普通表格行默认样式：
- 字号：14px
- 文字色：`#333333`
- 行高：44px
- 底部分割线：1px
- 间隔行背景：`#F9FAFD`

表格最后一行正文内部不额外显示底部分割线，但表格整体仍保留底部边框。

常见对齐建议：
- 名称、描述、编号、组织、状态：通常左对齐
- 金额、数量、比例、可比较数值：通常右对齐
- 短状态、日期、操作列、紧凑编码：可居中对齐

## 表格边框

表格使用轻量网格边界：
- 右边框：`rgba(230, 234, 238, 1)`
- 底边框：`rgba(230, 234, 238, 1)`
- 单元格分割线：`rgba(230, 234, 238, 1)`

如果页面本身已经有内容区域，不建议再把表格包进一个强装饰性的卡片。表格应该自然融入页面，而不是变成一个过度突出的容器。

## 操作列

行操作以主色文字按钮呈现。

默认规则：
- 颜色：`#005CF1`
- 操作之间间距：12px
- 悬浮态：轻微降低透明度
- 常见操作：编辑、保存、删除、上移、下移、查看

设计建议：
- 高频、低风险操作可以直接放在行内。
- 删除等风险操作尽量放在后面，必要时配合二次确认。
- 如果一行超过 3 个操作，建议在产品设计中考虑“更多”菜单。
- 操作文案尽量短，使用动词或动宾结构。

## 分页样式

分页位于表格下方。

默认规则：
- 距离表格顶部：15px
- 底部留白：5px
- 页码最小宽度：28px
- 页码圆角：4px
- 普通页码文字：`#888888`
- 当前页：主色文字 + 主色边框

当数据量较大时使用分页。少量固定数据可以不展示分页。

## 空数据状态

默认空态使用插图和文案 `暂无数据`。

设计建议：
- 普通无结果场景使用 `暂无数据`。
- 如果用户刚执行了筛选，可以使用更明确的文案，例如 `暂无符合条件的数据`。
- 不要在表格里使用过大的营销式空态。
- 空态应在表格内容区域中居中展示。

如果业务需要自定义空态，需要在设计说明中标注“使用自定义空态”。

## 异常状态

当表格因接口异常、权限异常或数据异常无法展示时，使用异常状态。

默认结构：
- 居中展示
- 图片尺寸：128px
- 图片与文字间距：12px
- 错误说明文字位于图片下方

异常状态和空数据状态要区分开。没有数据是正常业务状态，加载失败或无权限才是异常状态。

## 可编辑表格

可编辑表格的节奏比普通表格略高。

默认规则：
- 普通行高：44px
- 可编辑行高：48px
- 行内输入框高度：30px

设计建议：
- 行内编辑控件要紧凑，不要破坏表格节奏。
- 不建议在单元格中放置大面积表单控件、长说明或多行校验文案。
- 密集编辑场景可以使用错误角标或统一错误提示。
- 如果编辑内容复杂，优先考虑弹窗或抽屉，而不是强行塞进表格单元格。

## 文本溢出与提示

密集表格中默认推荐单行展示，超长内容使用省略和提示浮层。

适合使用提示浮层的内容：
- 长名称
- 长组织路径
- 长描述
- 需要完整查看的编号或编码

不要把关键决策信息完全藏在提示浮层里。如果用户需要跨行比较完整内容，应考虑加宽列、提供详情页或展开查看。

## 筛选和帮助图标

表头中的筛选和帮助信息使用轻量图标。

默认规则：
- 筛选图标：14px
- 帮助图标：17px
- 图标与表头文字基线对齐
- 未激活时保持弱强调，激活后可使用主色

帮助图标只用于解释专业术语、复杂口径或容易误解的字段。不要给每一列都加帮助图标。

## 滚动行为

当数据超出表格可视区域时，表格主体区域纵向滚动。

滚动条规则：
- 宽度：6px
- 默认透明或弱显示
- 鼠标悬浮时轻量显示
- 滑块圆角：3px

设计时要给表格主体留出足够高度，让滚动行为看起来自然。除非布局强约束，不建议只露出一两行数据的矮表格。

## 推荐页面组合

典型列表页建议结构：
1. 页面标题或面包屑
2. 查询/筛选区域
3. 工具栏或主操作按钮
4. 表格
5. 分页

表格周围的间距要克制。表头背景、分割线、斑马纹和分页已经提供了足够的结构感。

## 设计走查清单

交付表格设计前，建议检查：
- 表头是否为 44px 高度和浅蓝背景
- 表格行是否为 44px 高度和 14px 字号
- 边框是否使用标准浅灰分割线
- 行操作是否使用主色 `#005CF1`
- 当前分页是否使用主色文字和主色边框
- 空数据状态和异常状态是否区分清楚
- 固定列、操作列是否遮挡正文内容
- 长文本是否有省略、提示或详情方案
- 可编辑行是否保持紧凑，没有破坏表格节奏

## 允许偏离的场景

以下场景可以根据业务需要做适度调整：
- 审计或对比类表格可能需要更高信息密度
- 财务类表格可能需要更强的数值右对齐和金额强调
- 配置型可编辑表格可以默认使用 48px 行高
- 风险预警类表格可以增加状态标签或警示标记

发生偏离时，应在设计说明中写明原因，让开发知道这是有意设计，而不是视觉不一致。
