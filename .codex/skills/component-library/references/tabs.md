# Artisan UI Tabs 标签页样式规范

用于页面内同级内容切换，适合模块切换、列表分类、状态分组和多视图切换。

## 视觉规则

默认标签栏：
- 高度：46px
- 背景：白色
- 底部分割线：`#E8EAEC`
- 标签字号：16px
- 标签左右内边距：20px
- 图标与文字间距：4px

选中态：
- 文字使用主色 `#005CF1`
- 底部显示 2px 主色指示线
- 指示线圆角 2px

## 下拉标签

当标签数量过多时可以使用下拉：
- 下拉项字号：16px
- 选中/悬浮背景：`#E1EDFF`
- 选中/悬浮文字：`#0A62F1`

## 设计建议

- 标签用于同级切换，不用于页面主导航。
- 标签文案保持短，通常 2 到 6 个汉字。
- 当前标签必须清晰可见，避免只靠颜色表达。
- 标签数量过多时优先分组或使用下拉，不要挤压到换行。

## 走查清单

- 标签栏高度是否为 46px。
- 选中态是否有主色文字和底部指示线。
- 标签之间是否保持充足点击区域。
- 下拉态是否与普通选中态颜色一致。
