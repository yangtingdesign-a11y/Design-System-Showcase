# Artisan UI UploadImage 图片上传样式规范

用于头像、封面、截图、凭证等图片上传场景。

## 视觉规则

头像/方形上传：
- 尺寸：120px × 120px
- 边框：1px 虚线 `#D9D9D9`
- 圆角：4px
- 背景：`#F7F7F7`
- 悬浮边框：虚线 `#006AFF`
- 悬浮背景：`rgba(0, 106, 255, 0.10)`

添加图标：
- 字号：25px
- 颜色：`#999999`

说明文字：
- 字号：14px
- 颜色：`#999999`

预览图片：
- 头像图：120px × 120px
- 大图示例：358px × 198px

遮罩层：
- 覆盖图片全区域
- 背景：`rgba(100, 100, 100, 0.5)`
- 文字/图标：白色
- 默认透明，悬浮显示

失败状态：
- 文字颜色：`#F75858`
- 背景：`#F7F7F7`
- 头像失败高度：120px
- 大图失败高度：180px

## 设计建议

- 上传前、上传中、上传成功、上传失败都需要设计。
- 预览、删除等操作放在悬浮遮罩中。
- 图片比例要在设计稿中明确，避免上传后裁切不可控。
- 错误提示不要只用红色图标，应有文字说明。

## 走查清单

- 上传框是否为 120px 方形或明确的大图比例。
- 悬浮态是否有蓝色虚线和浅蓝背景。
- 遮罩操作是否可识别。
- 失败状态是否与普通空态区分。
